# HelpNaud.ai — project by FINECIA GROUPE

Gestion financière & outils IA. Application web en un seul fichier (`index.html`).

- `index.html` — l'application
- `netlify.toml` — configuration de déploiement Netlify
- `supabase/schema.sql` — schéma de base de données (à exécuter dans l'éditeur SQL de Supabase)
- `supabase/migration-auth.md` — plan de migration de l'authentification
- `supabase/netlify-plan.md` — plan de déploiement

Ne jamais déposer ici de clé secrète (`service_role`, clés API).
